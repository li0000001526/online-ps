# 在线PS · 免费在线图片编辑器

仿 FreePS / miniPaint / Photopea 的浏览器端 Photoshop 替代品，单文件实现，无需安装、无需服务器。

## 运行

直接双击打开 `index.html` 即可（或拖进任意浏览器）。所有功能 100% 在本地浏览器运行，图片不上传。

## 功能

| 分类 | 功能 |
|---|---|
| 文档 | 新建画布（预设/自定义）、打开图片（文件/拖拽/剪贴板粘贴）、导出 PNG/JPG |
| 图层 | 新建/复制/删除/重命名/排序（按钮或拖拽）、可见性、不透明度、12 种混合模式、合并可见 |
| 工具 | 移动、矩形选区（移动内容/删除/填充/复制粘贴）、裁剪、画笔、橡皮擦、油漆桶（容差）、渐变、文字、矩形、椭圆、直线、箭头、取色器 |
| 滤镜 | 灰度、反色、二值化、怀旧、亮度、对比度、饱和度、模糊、锐化、像素化（参数可调） |
| 图像 | 画布大小（锚点）、缩放图像（锁定比例）、旋转 90°、水平/垂直翻转 |
| 历史 | 40 步撤销/重做（Ctrl+Z / Ctrl+Shift+Z），历史记录面板可点击跳转 |
| 视图 | 缩放（Ctrl+滚轮）、适应窗口、实际大小、空格/中键平移 |

## 快捷键

见「帮助 → 快捷键」（Ctrl+F1 也可呼出帮助菜单）。

## 测试

```js
// 浏览器控制台 (打开 index.html 后)
window.PS.__selfTest.unit()   // 单元测试: 颜色/填充/滤镜/序列化
window.PS.__selfTest.flow()   // 流程测试: 画→填→图层→滤镜→撤销→文字→选区→旋转→导出
```

或粘贴 `test.js` / `flow-test.js` 文件内容到控制台。

## 技术说明

- 纯原生 HTML5 Canvas 2D，无任何外部依赖（图标为内联 SVG）
- 每图层独立 canvas，渲染时按混合模式/不透明度合成
- 撤销系统基于 ImageData 快照（上限 40 步）
- 油漆桶为扫描线洪泛填充；模糊为可分离盒式模糊；锐化为 USM 近似
